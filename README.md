# Homebrew Tap for reminder-cli

Homebrew tap for [reminder-cli](https://github.com/yancya/reminder-cli) - A CLI tool to manage iCloud Reminders on macOS.

> **Note:** This formula installs a prebuilt binary for Apple Silicon (arm64) only. Intel Mac support has been dropped (see [#3](https://github.com/yancya/homebrew-reminder-cli/issues/3)).

> **Note:** `Formula/reminder-cli.rb` is auto-generated by a [scheduled workflow](.github/workflows/update-formula.yml) from `Formula/reminder-cli.rb.tmpl`, which polls the latest [reminder-cli release](https://github.com/yancya/reminder-cli/releases) and rewrites the formula when a new version is published. Manual edits to `Formula/reminder-cli.rb` will be overwritten on the next run — change `Formula/reminder-cli.rb.tmpl` instead.

## Installation

```bash
brew tap yancya/reminder-cli
brew install reminder-cli
```

## Usage

After installation, run:

```bash
reminder-cli --help
```

For detailed usage instructions, see the [main repository](https://github.com/yancya/reminder-cli).

## Updating

```bash
brew upgrade reminder-cli
```

## Uninstallation

```bash
brew uninstall reminder-cli
brew untap yancya/reminder-cli
```
